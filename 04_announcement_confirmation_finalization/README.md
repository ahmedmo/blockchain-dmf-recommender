# Announcement, confirmation, and finalization

This stage contains the `AuthorizedNodeElection` smart contract and the recorded artifacts from the Douban Movie and Last.fm runs.

The finalized notebooks include contract compilation and deployment, Ganache connection, address registration, authorized-node announcement, member confirmations, and finalization.

Key artifacts include:

- `address_to_userid.csv` — registered-address mapping.
- `AuthorizedNodeElection.address.txt` — deployed contract address.
- `announce_ak_report.csv` — announcement transactions/results.
- `confirm_ak_report.csv` — confirmation transactions/results.
- `finalized_ak_report.csv` — finalization results.
- `ak_chain_announcements.csv` — machine-readable on-chain announcement summary.
