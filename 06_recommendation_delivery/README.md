# Recommendation delivery and verification

This stage contains the finalized recommendation-delivery notebooks, `RecommendationDelivery` contract artifacts, deployment records, on-chain registration/delivery records, recommendation-hash storage reports, and receiver-side verification outputs.

Douban Movie retains the recorded V1 delivery outputs, including on-chain delivery records and verification results.

Last.fm retains the finalized V2 hash-storage and validation outputs. Individual payload JSON files are not duplicated in this minimal provenance package because the aggregate delivery and validation records, hashes, transaction identifiers, and regeneration code are included.
